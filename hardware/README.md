# Hardware

This directory contains the schematic, PCB design, manufacturing files, and assembly data for the FPGA CPU Business Card.

The board is a functional 6-layer PCB built around an Intel/Altera MAX 10 FPGA. The FPGA implements a custom 8-bit CPU and drives eight onboard LEDs that display values generated by software running on the processor.

## Hardware Overview

The business card contains:

- Intel/Altera MAX 10 `10M02DCV36C8G` FPGA
- Custom 8-bit CPU implemented in FPGA logic
- 8 binary-output LEDs
- CR2032 coin-cell power supply
- 1.2 V FPGA core rail
- 2.5 V FPGA I/O rail
- Manual reset button
- Power switch
- JTAG programming interface
- Onboard MAX 10 configuration flash for standalone startup

The finished PCB measures approximately:

```text
88.9 mm × 50.8 mm
```

and uses a 6-layer stackup.
---

## FPGA

The board uses an:

```text
Intel/Altera MAX 10
10M02DCV36C8G
```

The MAX 10 was selected because it combines FPGA logic and non-volatile configuration memory in a compact package.

After the FPGA's internal configuration flash has been programmed, the card can configure itself automatically whenever power is applied. No external configuration-memory IC is required for normal operation.

The FPGA implements the custom CPU contained in the repository's [`rtl/`](../rtl/) directory.

---

## Power System

The card is powered by a replaceable CR2032 coin cell.

```text
CR2032
   |
Power Switch
   |
  VBAT
   |
   +----------> 1.2 V LDO ----------> FPGA Core
   |
   +----------> 2.5 V LDO ----------> FPGA I/O
```

### 1.2 V Rail

The 1.2 V rail powers the MAX 10 core supply.

The production design uses a fixed 1.2 V low-dropout regulator suitable for operation from the CR2032 supply.

### 2.5 V Rail

The 2.5 V rail powers the FPGA I/O banks and configuration/JTAG circuitry.

Local ceramic decoupling capacitors are placed near the FPGA power pins to provide high-frequency current during switching.

---

## LED Output

Eight LEDs provide an 8-bit binary output from the processor.

```text
LED7 LED6 LED5 LED4 LED3 LED2 LED1 LED0
 MSB                                  LSB
```

Each LED is driven through its own current-limiting resistor.

The business-card demonstration program calculates prime numbers and writes each result to an 8-bit output register.

For example:

```text
Decimal     LED Output

2           00000010
3           00000011
5           00000101
7           00000111
11          00001011
13          00001101
```

The LEDs hold the current value while the CPU calculates the next prime.

---

## Reset

The card includes a momentary reset button connected to the CPU reset input.

The FPGA design also implements a power-on reset delay so that the CPU remains in reset briefly while the FPGA and power rails initialize.

This allows the processor to begin execution automatically after the card is switched on.

---

## JTAG Programming

Programming is performed through a compact six-pad pogo-pin interface rather than a conventional boxed JTAG header.

The interface exposes:

```text
TCK
TMS
TDI
TDO
2.5V
GND
```

The 2.5 V connection provides the programmer with the target I/O voltage reference.

The JTAG/configuration interface includes external bias resistors for deterministic startup behavior.

The MAX 10 can initially be configured over JTAG using an Intel USB-Blaster compatible programmer. Its internal configuration flash can then be programmed so that the card boots autonomously whenever power is applied.

See [`docs/PROGRAMMING.md`](../docs/PROGRAMMING.md) for programming instructions.

## PCB

The PCB uses a 6-layer construction to provide sufficient routing density for the compact MAX 10 package while maintaining dedicated power/ground copper.

Key PCB features include:

- 6 copper layers
- Ground and power-plane routing
- Fine-pitch FPGA escape routing
- Via-in-pad routing around the FPGA
- Epoxy-filled and capped vias
- ENIG surface finish
- Top and bottom component assembly
- Silkscreen QR codes linking to project resources

The design was prepared for JLCPCB fabrication and assembly.

## Design Philosophy

The card was designed to remain a functional implementation of the original custom CPU rather than becoming dedicated LED-control logic.

The FPGA still executes machine code generated by the project's software toolchain. The LEDs are simply an output peripheral attached to the processor.

The business-card implementation reduces hardware resources where appropriate, particularly data-memory capacity, while retaining the core processor architecture and arithmetic capabilities.

This allows the complete system to fit within the small MAX 10 device while remaining representative of the larger CPU project.
